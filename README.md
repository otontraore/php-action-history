# PHP Action History

Record and inspect meaningful business actions, changes and events across PHP applications with Laravel and Symfony integrations.

> Status: foundation in development.

## Goals

This project is designed as a framework-agnostic PHP core with first-class Laravel and Symfony integrations.

## Development

Development happens on `dev`. Short-lived `feature/*` branches are used for individual tasks and integrated into `dev` without pull requests. `main` contains stable releases. Releases are identified with Git tags.

## Requirements

See the project documentation and Composer configuration for the supported PHP versions.
